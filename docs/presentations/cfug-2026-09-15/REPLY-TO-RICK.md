**Title:** Wheels: Rails-Style CFML — Building a Blog Live in 50 Minutes

Twenty years ago a fifteen-minute video of someone building a blog in Rails changed how a lot of us thought about web frameworks. Wheels brought those same ideas — convention over configuration, an ORM that generates parameterized SQL, scaffolding, migrations, tests as a first-class citizen — to CFML, and in the last year it has changed more than in the previous five. This session is the CFML version of that video. Starting from an empty directory, with no IDE and no configuration files, we'll build a working blog with posts, comments, user accounts with properly hashed passwords, default-deny authorization policies, a passing test suite, and a JSON API. Every command typed on screen is one you can type yourself that night.

Along the way we'll cover what Wheels actually is in 2026: a single Homebrew or Scoop install — macOS, Linux, or Windows — with no CommandBox required, support for Adobe ColdFusion 2018–2025, Lucee, BoxLang, and the new JVM-free RustCFML engine, seven database engines including SQLite and SQL Server, and a CLI that doubles as an MCP server so AI coding assistants can scaffold, migrate, and run tests against your real project. The talk is aimed at CFML developers who have an existing application in production and want a modern place to put the next feature — no rewrite required. We'll close with how to run Wheels alongside a legacy app and move one route at a time.
