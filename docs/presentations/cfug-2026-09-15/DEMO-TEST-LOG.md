**Gotchas found**
- ⚠️ If `wheels start` fails partway (here: the Lucee download was blocked), it leaves a registration
  in `~/.wheels/servers/blogdemo` and the next `wheels start` refuses: *"Server name 'blogdemo' is
  registered to a different project: registered: <unknown>"*. Recovery is `wheels start --force`.
  → Add `--force` to the run sheet's fallback table.
- 🐛 Debug bar "Code Complexity — app/" panel prints literal `#local.codeComplexity.summary.files#`
  etc. — the summary line is not interpolated (missing `<cfoutput>` or wrong scope) on a fresh app.
