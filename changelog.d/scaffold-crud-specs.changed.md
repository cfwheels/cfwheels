- `wheels generate scaffold` now emits full CRUD controller specs (`index`, `new`, `create`, `show`, `edit`, `update`, `delete`) with `processRequest` assertions and `model().create()` test data, matching the spirit of Rails scaffold controller tests. Sample attribute structs use quoted colon keys (`{"title": "MyString"}`) so CFML keeps the real property names — unquoted `{title = ...}` uppercases to `TITLE`, and quoted `"title" =` is a boolean equality expression, not a keyed entry. Re-generate existing apps with `--force` to pick up the richer specs.
